# Code

## code1.c and code1_2.s

gcc -o code1 code1.c
/code1 123 > code1_2.s

The first line compiles code1.c into the code code1 to create an executable file.

The second line passes the input 123 to code1 to generate the assembly code, which is the code1_2.s written to a file.

Then do:
>> gcc -o code1_2 code1_2.s
>> ./code1_2
>> echo $?
Output: 123

We have:
C source code
    ↓
our compiler (code1.c)
    ↓
assembly code (.s)
    ↓
gcc / cc
    ↓
machine-code executable
    ↓
CPU runs it

code1.c is the compiler program, however this program doesn't compile C code yet. It takes a number as input and produces assembly code. Once you compile code1.c using GCC, you get an executable (code1).

code1_2.s is assembly language.

It is the output that the compiler is supposed to produce.

So if using manually created code1_2.s, we have essentially skipped your compiler and manually written what the compiler should have generated.

>> ./code1 123
.intel_syntax noprefix 
.global main
main:
    mov rax, 123
    ret

>> echo $?
0

>> gcc -o code1 code1.c
>> ./test1.sh

>> echo $?

Replacing the last assert line
>> ./test1.sh

Note: running the above command created code1.s

| File      | What it is                              |
| --------- | --------------------------------------- |
| `code1.c` | Source code **of your compiler**        |
| `code1`   | The actual **compiler executable**      |
| `code1.s` | Assembly **generated by your compiler** |

"cc -o tmp code1.s" is not compiling your compiler, it is compiling the assembly that your compiler produced.

code1.c
    │
    │ gcc
    ▼
code1
    │
    │ ./code1 42
    ▼
code1.s
    │
    │ cc
    ▼
tmp

tmp is an executable.

GCC is compiling your compiler. cc takes the assembly generated by your compiler and turns it into an executable.

## Debugging

bash -x test1.sh
+ assert 0 0
+ expected=0
+ input=0
+ ./code1 0
+ cc -o tmp code1.s
+ ./tmp
+ actual=0
+ '[' 0 = 0 ']'
+ echo '0 => 0'
0 => 0
+ assert 42 42
+ expected=42
+ input=42
+ ./code1 42
+ cc -o tmp code1.s
+ ./tmp
+ actual=42
+ '[' 42 = 42 ']'
+ echo '42 => 42'
42 => 42
+ echo OK
OK
